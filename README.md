# Modularity on the Karate Club Graph (DSC212)

Recursive spectral modularity partitioning (Newman 2006) implemented from scratch with NumPy + NetworkX.

- `karate_modularity.ipynb` — runs top-to-bottom (`Kernel → Restart & Run All`), contains code, outputs, plots and discussion
- `partitions.png`, `metric_evolution_*.png` — saved figures

```
pip install -r requirements.txt
jupyter notebook karate_modularity.ipynb
```
